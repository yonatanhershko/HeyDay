# HeyDay Frontend

Welcome to the frontend repository of HeyDay, the first-ever finance system and marketplace for teenagers! This project is created using Expo.

## Table of Contents

- [Introduction](#introduction)
- [Features](#features)
- [Technologies](#technologies)
- [Usage](#usage)

## Introduction

HeyDay is a unique platform designed to help teenagers manage their finances and participate in a marketplace for buying and selling second-hand items. It combines financial education with practical tools to promote responsible money management from a young age.

## Features

- User Authentication
- Financial Dashboard
- Marketplace for second-hand items
- Parental Controls
- Educational Resources

## Technologies

- **Frontend:** Expo, React Native
- **Backend:** Flask (separate repository)
- **Database and Authentication:** Firebase

## Usage

1. Ensure the backend server is running (refer to the backend repository for instructions).
2. Start the Expo development server using `yarn expo start`.
3. Access the application on your device through the Expo app or a web browser.
